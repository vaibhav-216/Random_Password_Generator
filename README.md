# Random_Password_Generator
🔐 Random Password Generator

A simple and interactive Random Password Generator built using HTML, CSS, and JavaScript.
This project helps generate strong and secure passwords while improving logic-building skills in JavaScript.

🚀 Features
Generate random and secure passwords
Customize password length
Include:
Uppercase letters (A–Z)
Lowercase letters (a–z)
Numbers (0–9)
Special characters (!@#$%^&*)
Copy password to clipboard
Responsive and clean UI
🛠️ Tech Stack
HTML – Structure of the app
CSS – Styling and layout
JavaScript – Logic and functionality
📸 Preview

⚙️ How It Works
Select your desired password length
Choose character types (uppercase, lowercase, numbers, symbols)
Click on Generate Password
Copy and use your secure password
